# WolfGuard

Application web privée de gestion de mémos et procédures, de coffres chiffrés et de postes associés (scans réseau, protection antivirus, prise en main à distance).

Toute la documentation est dans [`documentation/`](documentation/README.md) : architecture, développement et tests, publication, sécurité, serveur et agents. Pour reprendre le travail, commencer par [Reprendre le projet](documentation/reprise.md).

Le dossier `docs/` est le site généré pour GitHub Pages : il ne se modifie jamais à la main.
